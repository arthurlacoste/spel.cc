How it works

One endpoint.
Your whole toolbox.

Gate runs beside your tools. It authenticates ChatGPT, namespaces configured MCP subservers, streams commands and lets Skills remain discoverable without injecting everything into every conversation.

01 / connect

OAuth-protected access

Expose one stable public MCP endpoint while signing tokens with a local RSA key.

02 / compose

Configurable subservers

Bring browser automation, custom MCP servers and other tools behind a clear namespace.

03 / operate

Streaming local commands

Execute work locally, inspect output as it arrives and keep the underlying services off somebody else’s cloud.

Available tools

Useful primitives.
