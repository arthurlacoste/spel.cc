How we build

Less platform.
More capability.

Agentic software should extend what people can do without hiding the machine, trapping the data or turning every task into a subscription-shaped maze.

01 / local

Keep control close

Commands, files and services stay on your machine when the cloud adds no real value.

02 / composable

Connect what exists

Use MCP, scripts and open formats instead of rebuilding the universe behind a private API.

03 / direct

Remove the ceremony

Short paths from request to result. Software already has enough meetings with itself.

Open source by default

Build with us, fork the useful parts.

The projects are public, inspectable and designed to be adapted. Because ownership is nicer than dependency cosplay.
